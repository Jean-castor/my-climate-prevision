# MyClimate

MyClimate é uma aplicação web que fornece informações meteorológicas atuais e previsões para os próximos cinco dias. A aplicação utiliza a API do OpenWeatherMap para obter os dados meteorológicos.

## Funcionalidades

- Busca de informações meteorológicas atuais por cidade.
- Exibição de previsão do tempo para os próximos cinco dias.
- Alteração dinâmica da imagem de fundo com base na descrição do clima.
